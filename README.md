# Stock Portfolio Tracker

A simple stock portfolio tracker written in Python, created for my CodeAlpha Python Programming Internship (Task 2).

## About

The user enters stock names and quantities. The program uses a hardcoded dictionary of stock prices to calculate the total investment value.

## Features

- Hardcoded prices for AAPL, TSLA, GOOGL, MSFT, and AMZN
- Accepts multiple stocks until the user types done
- Validates stock names and quantities
- Displays a summary and the total investment
- Option to save the result to portfolio.txt

## Concepts Used

Dictionaries, loops, input/output, basic arithmetic, error handling, file handling

## How to Run

1. Install Python 3 from [python.org](https://www.python.org).
2. Download stock_tracker.py.
3. Run in a terminal: python stock_tracker.py (or open it in IDLE and press F5).

## Example


Stock name: AAPL
Quantity: 10
Stock name: done
Total investment: $1800
